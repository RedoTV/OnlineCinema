# Changelog

Все заметные изменения проекта в хронологическом порядке.

## [v2.0.0] — 2026-09-03 — «Профессиональный фундамент»

Демо-тема выпуска: _монолит превратился в стриминговую платформу с
современной доставкой видео, соцфичами и масштабируемой инфраструктурой._

### Возможности, которые можно увидеть

- Сериалы: полная поддержка сезонов/эпизодов, страница сериала,
  каталог с поиском
- Комментарии с ответами и лайками, сортировка (по популярности/дате),
  модерация от админа
- Плеер на Plyr с сохранением позиции («продолжить с того же места»)
- Видео стримится по presigned-URL из MinIO — Range requests, никакой
  буферизации гигабайтов на бэкенде
- Минимальная статистика: топ по оценкам, по просмотрам, жанры

### Технические правки

- Апгрейд .NET 8 → .NET 10 (SDK 10.0.204, pinned в global.json)
- Хранилище: UseStaticFiles выпилен, вместо него IStorageService +
  MinIO с абстракцией под S3
- AutoMapper 12 → 16 (зачистил CVE GHSA-rvv3)
- PasswordHasher на Rfc2898DeriveBytes.Pbkdf2, итерации 10k → 600k
- Защита секретов: выпилил .env и mp4 из истории (git-filter-repo),
  ротация паролей
- Демо-сидинг, смоук-тест и Postman коллекция вместо .http файлов
- CI/CD в GitHub Actions (сборка, линт, юнит-тесты, смоук, релиз на тег)

### Известные проблемы

- CS8602-предупреждение в Include-цепочке PlaybackService подправлено
  прагмой (ложное срабатывание).
- Серии где-то висят без превью-картинки, пока загрузка не вписана в UI.
